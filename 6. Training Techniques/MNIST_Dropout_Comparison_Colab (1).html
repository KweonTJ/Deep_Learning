과제: Google Colab에서 MNIST 데이터에 Dropout을 적용하기 전후의 학습 성능과 오버피팅을 비교하고 결과를 설명합니다.

기준 소스: WegraLee/deep-learning-from-scratch

  • ch06/overfit_dropout.py
  • ch06/overfit.py
  • common/multi_layer_net_extend.py

실험 설계: 학습 데이터 300개, 6개 은닉층(각 100 뉴런), SGD(학습률 0.01), 배치 100개, 301 epochs, Dropout 비율 0.2. 같은 가중치 초깃값과 동일 미니배치를 사용하여 Dropout 사용 여부만 변경합니다. 실행 시간 절감을 위해 매 10 epochs마다 학습 및 평가용 테스트 샘플 1,000개에 대한 지표를 기록하며, 마지막에 전체 MNIST 테스트 10,000개로 최종 정확도를 계산합니다.

3. Dropout 미적용 / 적용 모델 생성¶

MultiLayerNetExtend의 실제 생성자 인자는 dropout_ration 입니다. 원본 소스에서 이 철자를 사용하므로 dropout_ratio로 변경하면 오류가 발생합니다.

In [3]:
SEED = 42
BATCH_SEED = 2026
EPOCHS = 301
BATCH_SIZE = 100
LEARNING_RATE = 0.01
DROPOUT_RATIO = 0.2
EVAL_INTERVAL = 10

models = {}
optimizers = {}

for name, use_dropout in [('No Dropout', False), ('Dropout (0.2)', True)]:
    np.random.seed(SEED)  # 두 모델의 초기 가중치 동일하게 맞춤
    models[name] = MultiLayerNetExtend(
        input_size=784,
        hidden_size_list=[100, 100, 100, 100, 100, 100],
        output_size=10,
        use_dropout=use_dropout,
        dropout_ration=DROPOUT_RATIO
    )
    optimizers[name] = SGD(lr=LEARNING_RATE)

same_init = all(

4. 같은 미니배치로 두 모델 학습¶

Dropout 미적용 / 적용 모델 모두 동일한 미니배치 인덱스를 사용합니다. 모델별 학습 정확도와 평가용 테스트 정확도를 저장합니다.

In [4]:
rng = np.random.default_rng(BATCH_SEED)
iter_per_epoch = int(np.ceil(len(x_train) / BATCH_SIZE))

history = {
    name: {'epoch': [], 'train_acc': [], 'test_acc': [], 'train_loss': [], 'test_loss': []}
    for name in models
}

for epoch in range(1, EPOCHS + 1):
    for _ in range(iter_per_epoch):
        idx = rng.integers(0, len(x_train), size=BATCH_SIZE)
        x_batch, t_batch = x_train[idx], t_train[idx]
        for name, network in models.items():
            grads = network.gradient(x_batch, t_batch)
            optimizers[name].update(network.params, grads)

    if epoch == 1 or epoch % EVAL_INTERVAL == 0 or epoch == EPOCHS:
        logs = []
        for name, network in models.items():
            h = history[name]
            h['epoch'].append(epoch)
            h['train_acc'].append(network.accuracy(x_train, t_train))
            h['test_acc'].append(network.accuracy(x_test_eval, t_test_eval))
            h['train_loss'].append(network.loss(x_train, t_train, train_flg=False))
            h['test_loss'].append(network.loss(x_test_eval, t_test_eval, train_flg=False))
            logs.append(f"{name}: train={h['train_acc'][-1]:.3f}, test={h['test_acc'][-1]:.3f}")
        print(f"Epoch {epoch:3d}/{EPOCHS} | " + ' | '.join(logs))

print('Training finished.')

8. 과제 결과¶

1. 최종 실험 결과¶

평가 지표 Dropout 0.0 Dropout 0.1 Dropout 0.2
학습 정확도 100.00% 99.33% 68.67%
테스트 정확도 75.67% 75.51% 54.38%
일반화 격차 24.33%p 23.82%p 14.09%p

2. 결과 분석¶

  • Dropout 0.0 : 학습 정확도가 100%, 테스트 정확도 75.67% 기록. 학습 데이터에 대한 오버피팅이 뚜렷하게 나타남
  • Dropout 0.1 : 학습 정확도 99.33%, 테스트 정확도 75.51% 기록. 일반화 격차는 0.51%p 감소, 테스트 정확도는 0.16%p 감소. 오버피팅 억제 효과가 제한적
  • Dropout 0.2 : 학습 정확도 68.67%, 테스트 정확도 54.58% 감소. 학습이 충분히 진행되지 않은 상태로 판단.
  • 결론 : 현재 301 Epoch 조건에서는 Dropout 0.0이 가장 높은 테스트 정확도 달성. Dropout 비율이 높을수록 정확도가 감소하는 경항 관찰, 0.2에서 학습 부족 현상 나타남.
